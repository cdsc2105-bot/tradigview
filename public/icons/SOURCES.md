# Icon sources

All logos are the official marks of their projects and companies, used only to
identify each asset. They are copied unmodified from open icon packages:

- `crypto/` — [web3icons](https://github.com/0xa3k5/web3icons) (MIT), via the
  Iconify `token-branded` set (`<name>-background` variants). HYPE uses the
  Hyperliquid `hyper-evm` mark, WLD the `world` mark and RENDER the `rndr` mark
  from the same set. `crypto/` also covers the exchange tokens it ships.
- `stocks/` — [SVG Logos](https://github.com/gilbarbara/logos) (CC0): AAPL,
  GOOGL, META, MSFT, NFLX. [Simple Icons](https://simpleicons.org) (CC0),
  colored with the brand hex Simple Icons publishes: NVDA, AMD, TSLA, MSTR;
  AMZN in Amazon's brand orange (#FF9900). COIN: Coinbase mark from web3icons.

Assets without an official logo in these sets (e.g. ENA, ONDO, WIF, FARTCOIN,
and the indices) show a neutral placeholder instead of an invented logo.
